Plataforma de publicações acadêmicas

Um mural digital para o que o professor precisa dizer.

EduMural é o espaço onde professores publicam avisos, materiais, atividades e provas — e alunos acompanham tudo em um só lugar. Este documento reúne cores, tipografia, componentes e padrões de uso da interface.

Tipografia

02 / Fundamentos

Space Grotesk assina os títulos com um tom técnico e contemporâneo. Inter carrega o corpo do texto pela leitura longa. IBM Plex Mono marca metadados — datas, categorias, contadores — como se fossem carimbos de registro.

Selos de categoria

04 / Elemento assinatura

Todo post carrega um selo — como um carimbo de secretaria acadêmica. É o primeiro elemento que o aluno lê: define se aquilo é urgente, informativo ou uma obrigação com prazo. A leve rotação reforça a ideia de "carimbado à mão".
